# The q Tool

`q` is a command-line tool for calling the Service Infrastructure APIs. It can be used alongside or in place of [gcloud](https://cloud.google.com/sdk/gcloud), and its code provides an examples of Go usage of the Service Infrastructure APIs.

To get started with `q`, try the [demo](/docs/quickstart/demo).

Full source code for `q` is on GitHub at [github.com/agentio/q](https://github.com/agentio/q) and a container build that also includes `gcloud` is available at [ghcr.io/agentio/q:nightly](https://github.com/agentio/q/pkgs/container/q).

For more about how `q` works, see [How to Call Google APIs](/docs/details/how-to-call-google-apis).
