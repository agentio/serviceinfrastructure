## Managing APIs with OpenAPI

The Cloud Endpoints product includes support for OpenAPI API descriptions. Currently only OpenAPI 2.0 is supported
([esp#446](https://github.com/cloudendpoints/esp/issues/446), 
[esp-v2#500](https://github.com/GoogleCloudPlatform/esp-v2/issues/500)).

For full details, see the [Cloud Endpoints for OpenAPI documentation](https://cloud.google.com/endpoints/docs/openapi).
